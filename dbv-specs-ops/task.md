## ⚠️ Deuda Técnica Abierta

- **`src/app.js` contiene 4 bytes NUL (`\x00`) literales, usados como delimitador del placeholder `MATH_PROTECT_RE` — Git/GitHub tratan el fichero entero como binario.** Documentado por primera vez el 2026-08-18 (ADR-026, contexto de un conflicto de merge de PR), pero nunca había quedado como punto de "Deuda Técnica Abierta" rastreable hasta ahora (2026-08-20, Lección 25 en `memory.md`) — vuelto a topar con esto al forzar `git diff -a` para poder ejecutar el `/code-simplify` de esta sesión. Funcionalmente correcto (verificado), pero rompe `git diff`/la vista de diff de GitHub para cualquier cambio futuro sobre este fichero — cualquier PR sobre `app.js` se verá como "Binary file not shown" en GitHub. **No corregido** (fuera del foco de las sesiones que lo han encontrado hasta ahora). Arreglo sugerido cuando se aborde: sustituir el delimitador NUL por una secuencia de texto imposible de colisionar con markdown real (ej. un UUID fijo o un marcador con caracteres poco comunes pero imprimibles) en `mathPlaceholder`/`MATH_PROTECT_RE`/`stash()`, verificando que las 4 apariciones cambien juntas.
