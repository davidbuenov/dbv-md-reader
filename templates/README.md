# Plantillas / Templates

🇪🇸 Colección de plantillas Markdown listas para usar. Copia el archivo que necesites con otro nombre (dbv-md-reader aún no tiene "Guardar como" — Ctrl+S sobreescribe el archivo abierto), ábrelo con **dbv-md-reader** en Modo Edición y rellena los campos entre `[corchetes]`.

🇬🇧 A collection of ready-to-use Markdown templates. Copy the file you need under a new name first (dbv-md-reader doesn't have "Save As" yet — Ctrl+S overwrites the open file), then open it with **dbv-md-reader** in Edit Mode and fill in the fields between `[brackets]`.
